Cluster

From the adjacent Achieve directory, run node start-cluster.mjs. It starts the single-process server on port 8989 and the clustered server on port 8990.

SCENARIO: Your application needs more processing power than a single Node.js process can provide.

Node's cluster support lets Achieve run multiple worker processes across multiple CPU cores.

This demonstration runs 16 CPU-intensive prime-number calculations first with a single Achieve process and then with multiple Achieve cluster workers.

The test runs automatically. The results below show the elapsed time for each batch.
