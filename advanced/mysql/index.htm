MySQL

From the adjacent Achieve directory, run node start-mysql.mjs. Before using the forms, run advanced/mysql/setup.sql on a MySQL-compatible server and set the database credentials in both servlets.

This demonstration connects an Achieve application to a MySQL database using the mysql2 package.

Register a user, then log in with the same user name and password. Achieve handles the HTTP request and parameters while the servlet uses mysql2 to communicate with the database.
